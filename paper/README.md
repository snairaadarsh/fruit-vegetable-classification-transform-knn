## Research Paper Information

**Title:**  
Efficient Classification of Fruits and Vegetables in Extensive Agricultural Fields Using Transform Techniques and KNN

**Authors:**  
Aadarsh S Nair, Panyam Narahari Sastry, Vivek Singh Kushwah

**Abstract (Brief):**  
This work presents a transform-based approach for the automated classification of fruits and vegetables in extensive agricultural fields. A custom image dataset was created under controlled conditions, followed by manual preprocessing to ensure consistency. Spectral features were extracted using two-dimensional Discrete Cosine Transform (DCT) and Fast Fourier Transform (FFT), and classification was performed using a K-Nearest Neighbour (KNN) classifier. Hybrid transform models were further explored to enhance recognition accuracy. Experimental results demonstrate that the proposed hybrid approach achieves improved classification performance with reduced computational complexity.
