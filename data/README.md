## Dataset Information

The dataset consists of fruit and vegetable images captured using
a mobile phone camera under controlled conditions.

### Preprocessing Details
All images were manually preprocessed using Adobe Photoshop prior to
model training. Manual preprocessing included:
- Background removal / background cleaning
- Cropping and centering of objects
- Resizing to 100×100 pixels
- Illumination and contrast normalization

This step ensured uniformity and consistency across the dataset.
